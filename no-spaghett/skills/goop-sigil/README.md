# GOOP-SIGIL

Detects and describes **system anomalies** (spaghetti code, deadlock, zombie processes, race conditions, dependency hell) using **mythological pattern language** — then outputs **practical fixes**. Bridges the gap between "what the logs say" and "what the engineer feels."

## The GOOP-SIGIL Doctrine

This skill does not believe in literal demons. 
It believes in complexity that *feels* demonic.

It uses myth to:
- name the unnameable
- tame the untamable
- debug the undebuggable

You are not an exorcist. 
You are an engineer using folklore as a cognitive tool.
