# PURPCLAW vs Odysseus Beat Plan

Date: 2026-06-02
Target: https://github.com/pewdiepie-archdaemon/odysseus

## Blunt Read

Odysseus is ahead on product breadth, first-run polish, auth/security posture,
Docker packaging, and regression tests. PURPCLAW should not try to win by
copying every workspace app at once. PURPCLAW wins by becoming the better API
harness: one job spine, visible agent delegation, tool proof, model routing,
research room, memory-aware execution, and repeatable verification.

## What Odysseus Has That Matters

- Chat across local/API providers.
- Agent mode with MCP, files, shell, web, skills, and memory.
- Cookbook: hardware scan, model fit, downloads, serve engines.
- Deep Research with visual reports.
- Model compare/blind testing.
- Documents, notes, tasks, email, calendar, gallery/uploads.
- ChromaDB/SearXNG/ntfy Docker bundle.
- Auth, roles, 2FA, API tokens, threat model.
- Large regression test suite.
- Docker/native/macOS/Windows launch docs.

## PURPCLAW Winning Position

PURPCLAW should become the self-hosted AI operations cockpit:

1. User says hello.
2. Chat stays chat-only unless there is an actionable request.
3. Actionable request becomes a kernel job.
4. Kernel job routes to swarm, harness, research, or model serving.
5. Every job shows exact proof: agents used, files touched, commands run,
   tests passed, approvals requested, final report.
6. The operator can approve, redirect, replay, or benchmark the whole chain.

## Critical Lanes

### One Launcher

Odysseus wins fresh install right now. PURPCLAW needs one Windows-first command
that starts the core stack, detects occupied ports, prints the Mission Control
URL, and shows a health report.

### Model Doctor / Cookbook

Build a PURPCLAW model doctor before a full cookbook:

- CPU/RAM/GPU/VRAM probe.
- Ollama/OpenRouter/OpenAI/local endpoint probe.
- Recommended models by hardware fit.
- One-click serve path later.
- Real logs in Mission Control.

### Security Gate

Odysseus has a real threat model. PURPCLAW needs identity and role gates around
dangerous tools:

- shell
- filesystem write/delete
- model serving
- secrets/settings
- MCP management
- email/calendar actions

### Research Room

PURPCLAW can beat Odysseus here if the OpenRouter free-model group room becomes:

- persistent kernel job
- source-cited report
- dissent/consensus view
- local Ollama fallback
- exportable visual report

### Proof Gates

`npm run cibuild` cannot stay an echo. It needs to run real smoke checks:

- Unified API syntax and health.
- chat -> kernel -> swarm route.
- research route.
- provider fallback route.
- Mission Control type check.
- governance denial test.

## Do Not Do

- Do not clone Odysseus feature-for-feature before the job spine is bulletproof.
- Do not add more tabs without a kernel job connection.
- Do not call it better until fresh install, security, and tests are credible.
- Do not hide broken optional services as if they are working.

## Build Order

1. Finish API kernel as the single front door.
2. Add first-run doctor and one launcher.
3. Replace fake CI with real smoke gates.
4. Add model doctor.
5. Persist research reports as kernel jobs.
6. Add auth/role gates.
7. Add repo/project intake as the first real workspace module.
8. Then add notes/tasks/docs/email/calendar if they attach to jobs.
