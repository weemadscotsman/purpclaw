# Keyboard Commands & Shortcuts Reference

## Windows System Shortcuts
### General System
- `Win + E`: Open File Explorer
- `Win + D`: Show desktop
- `Win + L`: Lock computer
- `Win + R`: Open Run dialog
- `Win + Tab`: Task view
- `Ctrl + Shift + Esc`: Task Manager
- `Alt + Tab`: Switch between windows
- `Alt + F4`: Close active window
- `Ctrl + Alt + Delete`: Security options

### File Operations
- `Ctrl + C`: Copy
- `Ctrl + X`: Cut
- `Ctrl + V`: Paste
- `Ctrl + Z`: Undo
- `Ctrl + Y`: Redo
- `Ctrl + A`: Select all
- `Ctrl + F`: Find
- `Ctrl + S`: Save
- `Ctrl + P`: Print
- `Ctrl + N`: New file/window
- `Ctrl + O`: Open file
- `F2`: Rename selected item
- `Delete`: Delete selected item
- `Shift + Delete`: Permanent delete

### Text Editing
- `Ctrl + Home`: Go to beginning of document
- `Ctrl + End`: Go to end of document
- `Ctrl + Left/Right Arrow`: Move by word
- `Shift + Arrow Keys`: Select text
- `Ctrl + Shift + Arrow Keys`: Select by word
- `Home`: Go to beginning of line
- `End`: Go to end of line

## Browser Shortcuts
### Navigation
- `Ctrl + T`: New tab
- `Ctrl + W`: Close tab
- `Ctrl + Shift + T`: Reopen closed tab
- `Ctrl + Tab`: Switch to next tab
- `Ctrl + Shift + Tab`: Switch to previous tab
- `Ctrl + L`: Focus address bar
- `Alt + Left Arrow`: Back
- `Alt + Right Arrow`: Forward
- `F5`: Refresh page
- `Ctrl + F5`: Hard refresh

### Page Operations
- `Ctrl + F`: Find in page
- `Ctrl + D`: Bookmark page
- `Ctrl + J`: Downloads
- `Ctrl + H`: History
- `Ctrl + P`: Print page
- `Ctrl + S`: Save page
- `Space`: Scroll down
- `Shift + Space`: Scroll up

## Application-Specific Shortcuts
### Command Prompt/Terminal
- `Ctrl + C`: Cancel current operation
- `Ctrl + V`: Paste (in newer terminals)

- `Ctrl + Shift + N`: New terminal window

### Text Editors/IDE
- `Ctrl + /`: Comment/uncomment
- `Ctrl + F`: Find
- `Ctrl + H`: Find and replace
- `Ctrl + G`: Go to line
- `F12`: Developer tools
- `Ctrl + Shift + I`: Inspect element

## Command Line Instructions
### Basic Commands
- `dir`: List directory contents
- `cd`: Change directory
- `cls`: Clear screen
- `exit`: Close terminal
- `ping`: Test network connectivity
- `ipconfig`: Network configuration
- `tasklist`: List running processes
- `taskkill`: Terminate processes

### File Operations
- `copy`: Copy files
- `move`: Move files
- `del`: Delete files
- `mkdir`: Create directory
- `rmdir`: Remove directory
- `type`: Display file contents

### System Commands
- `systeminfo`: System information
- `wmic`: Windows Management Instrumentation
- `powershell`: Open PowerShell
- `cmd`: Open Command Prompt

## AI Control Instructions
### Screen Interaction
1. **Before clicking**: Always use OCR to read button text
2. **Coordinate precision**: Use exact screen coordinates
3. **Wait states**: Allow time for applications to respond
4. **Error handling**: Take screenshot if operation fails

### Text Input
1. **Clear fields**: Use Ctrl+A before typing new text
2. **Special characters**: Use proper escape sequences
3. **Multi-line**: Use Enter for new lines
4. **Verification**: Read back typed text for accuracy

### Window Management
1. **Focus verification**: Confirm correct window is active
2. **Title matching**: Use exact window titles
3. **Safe closing**: Save work before closing windows
4. **Process monitoring**: Check for unresponsive applications

### File Operations
1. **Path validation**: Verify file paths exist
2. **Backup important**: Copy before deleting/modifying
3. **Permission checks**: Confirm access rights
4. **Error recovery**: Handle permission denied errors

## Advanced Control Patterns
### Multi-step Operations
1. **Sequence planning**: Plan complete operation before starting
2. **State verification**: Confirm each step completed successfully
3. **Rollback capability**: Know how to undo operations
4. **Progress monitoring**: Track long-running operations

### Error Recovery
1. **Screenshot evidence**: Capture error states
2. **Log analysis**: Read error messages via OCR
3. **Alternative methods**: Have backup approaches
4. **System restore**: Know recovery procedures

## Safety Protocols
### Critical Operations
1. **Confirmation required**: Delete, format, shutdown operations
2. **Backup verification**: Confirm backups before destructive actions
3. **Process priority**: Don't terminate system processes
4. **Data integrity**: Verify file operations completed successfully

### System Stability
1. **Resource monitoring**: Watch CPU/memory usage
2. **Network awareness**: Check connectivity before network operations
3. **Storage space**: Verify disk space before large operations
4. **Application conflicts**: Check for running applications that may conflict
