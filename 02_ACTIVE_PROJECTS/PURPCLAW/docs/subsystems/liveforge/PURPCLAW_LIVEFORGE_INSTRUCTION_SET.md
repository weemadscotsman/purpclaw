# PURPCLAW LIVEFORGE Instruction Set

LIVEFORGE is the safe substrate for generated operational surfaces. Every
surface, event, receipt, and learned correction must be represented as a typed
record and written to durable local storage before later phases render or act.

Phase 1 is storage and contracts only. It creates the audit lane that later
connects chat, memory, self-evolution, agent routing, skill loading, and tool
execution without relying on hidden UI state.
