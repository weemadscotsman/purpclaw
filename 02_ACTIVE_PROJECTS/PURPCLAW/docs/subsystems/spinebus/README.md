# PURPCLAW SPINEBUS Phase 2 Pack

SPINEBUS is the routing and orchestration layer that makes every PURPCLAW job pass through the full stack without turning the stack into a slow, noisy swamp.

It connects:

- Chat intake
- Intent normalization
- Seven-layer memory touch
- Fungus Amongus mycelium recall and broadcast
- Agent Tower and division selection
- Skill card loading
- Tool and function registry lookup
- PXPIPE artifact offload
- LIVEFORGE surface/event/receipt lane
- Execution gate
- Truth audit
- AutoLearn lesson queue
- DreamForge offline evolution queue

Core rule:

Every subsystem is touched. Only the right subsystem executes.

A touch means:
- inspect
- enrich
- decline
- warn
- route
- log

A run means:
- execute a tool
- mutate state
- write files
- call a provider
- perform system action

No subsystem gets to run just because it exists. That is how software becomes a haunted cupboard.
