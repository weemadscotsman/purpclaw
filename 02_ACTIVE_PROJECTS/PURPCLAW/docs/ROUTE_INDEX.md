## Interpretation

- A route file proves that a source entrypoint exists; it does not prove a healthy deployment.
- Dynamic segments are shown in Next.js notation, such as `[id]` and `[[...action]]`.
- Mutating routes remain subject to their source-level authentication and policy gates.
- Run `npm run docs:check` after adding, removing, or renaming a route.
