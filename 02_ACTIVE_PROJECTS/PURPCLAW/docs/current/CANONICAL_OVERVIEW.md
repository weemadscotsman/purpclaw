# Canonical Overview

Last updated: 2026-07-20.

PurpClaw is a local-first AI workstation OS, not the identity of any external
harness. Oracle is the coordinating intelligence role. Hermes is an internal
engineering chair/profile. Companions add presence while policy, evidence, and
operator approval retain authority.

The runtime joins CLI, TUI, Mission Control, optional gateways, provider routing,
governed tools, sessions, memory, MCP, orchestration, delegation, checkpoints,
and verification. Its distinctive organisation layer includes Council, Studio,
Timeline, Presence, Residue, Soul boundaries, and Donor Archaeology.

Current counts and health are intentionally omitted; use generated audits and
live probes.
