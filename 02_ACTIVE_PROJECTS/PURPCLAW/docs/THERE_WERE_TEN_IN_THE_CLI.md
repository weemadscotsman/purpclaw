# There Were Ten in the CLI
*A PURPCLAW Parable*

---

There were nine in the CLI,
And the little one said,
> "More token...
> More token..."

So the operator bought another sub,
Spun another agent,
Opened another terminal,
And there were...

**TEN IN THE CLI.**

---

Meanwhile...

```
CLI #1:
  "I've finished."

CLI #2:
  "I've also finished."

CLI #3:
  "I found another bug."

CLI #4:
  "I fixed it."

CLI #5:
  "I found six more."

CLI #6:
  "I've rebuilt the renderer."

CLI #7:
  "I've rewritten the documentation."

CLI #8:
  "I've audited the documentation."

CLI #9:
  "I've audited the audit."

You:
  "Excellent...
  launch another one."
```

---

Somewhere, one tiny CLI is still piping up every few minutes:

> **"Please remember to pay your subs at the end of the month..."**

while the other nine completely ignore it
and carry on chewing through another hundred million tokens.
