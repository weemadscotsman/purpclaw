# SPEC-015: Steering Registry

**Spec version:** 1.0.0
**Date:** 2026-07-20
**Steering vNext item:** S15
**Source:** PURPCLAW original

## Purpose

Every steering item (S0 through S15) has a registry entry with current status, owner, probe path, and evidence. The registry is the single source of truth for "what is the actual state of steering in this installation." It starts immediately and runs throughout — it is never finished.

## Verdict Definitions

| Verdict | Meaning |
|---------|---------|
| `NATIVE` | Fully implemented with passing probe, matches reference behavior |
| `ADAPTED` | Implemented but differs from reference — documented adaptation |
| `EMULATED` | Implemented via workaround — not native to this harness |
| `DEGRADED` | Partially implemented — reduced capability vs reference |
| `UNIMPLEMENTED` | Spec written, code not built |
| `UNTESTED` | Code exists, no probe written |
| `BROKEN` | Probe fails |

## CLI Commands

```bash
# View registry
purpclaw steering status        # human-readable table

# Run all steering probes
purpclaw steering probe         # runs all implemented probe paths

# Verify specific item
purpclaw steering verify S0    # runs S0 probe, updates registry

# Report drift
purpclaw steering drift         # items whose spec changed since last probe
```
