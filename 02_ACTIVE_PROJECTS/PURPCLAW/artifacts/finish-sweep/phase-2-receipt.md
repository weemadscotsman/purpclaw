## Architectural decisions
1. **Dual dispatch**: registry lookup first; registry-only commands route straight to their module; switch-handled commands fall through to the legacy switch unchanged. The CLI stayed usable at every migration step, and a mechanical drift test now fails if the registry and switch disagree.
2. **Unknown commands are errors** (stderr, did-you-mean, exit 2) — never silently reinterpreted as natural-language tasks. NL work belongs to `purpclaw run <goal>` / `purpclaw ask`.
3. Module-override map for name≠module commands (`personas` → roster module, `app` → desktop module).
4. Help index, `help <command>`, and all three shell completions derive from the registry — no second hand-maintained command list can drift.
5. npm hygiene done with negation globs inside `files` plus two explicit excludes (`apply-patch.debug.js`, `skills.js.debug`) because globs cannot match `.debug` mid-filename.
