**Last major update:** 2025 (Mem0 Graph, multi-modal, enterprise)

---

## What it is
Memory layer for AI apps and agents. Drop-in add-on that extracts, stores, and retrieves memories from conversations. Self-hostable vector store + LLM extraction pipeline.

## Core capabilities
- [x] Automatic memory extraction
- [x] Memory search (semantic + temporal)
- [x] User/session/agent memory
- [x] Multi-modal (text + image)
- [x] Mem0 Graph (knowledge graph memory)
- [x] Vector store agnostic (Qdrant, Pinecone, Chroma)
- [x] LLM-agnostic
- [x] Multi-language SDK
- [x] Self-host or cloud
- [x] Add/delete/update operations

## Architecture
```python
from mem0 import MemoryClient
client = MemoryClient(api_key="...")
client.add("User prefers Python", user_id="alice")
results = client.search("user preferences", user_id="alice")
```
- Extraction LLM + embedding LLM
- Vector store backend

## Strengths
- Drop-in memory layer
- Open source
- Multi-modal
- Active development

## Weaknesses
- Quality depends on extraction LLM
- Cloud costs add up
- Graph feature newer

## Best use case
Personalized AI apps, agents needing user memory, long-running sessions, anything needing "remember what user said yesterday".
