## What it is
Browser-based autonomous agent UI. Spin up an agent, give it a goal, watch it loop. Originally viral demo, now enterprise positioning.

## Core capabilities
- [x] Browser-based UI
- [x] Autonomous task execution
- [x] Goal-based prompts
- [x] Web browsing
- [x] Code generation
- [x] Multi-LLM
- [x] Self-host option

## Architecture
- Next.js frontend
- Loop-based execution
- Tools via plugins

## Strengths
- Lowest barrier (just open URL)
- Polished UI
- Self-host available

## Weaknesses
- Limited customization
- Loops easily derail
- Not a true framework (it's an app)
- Vendor API costs

## Best use case
Demos, casual experimentation, non-technical users exploring agents.
