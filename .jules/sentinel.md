## 2024-05-24 - Unauthenticated SSRF & RCE in Playwright Endpoint
**Vulnerability:** The `/api/playwright` endpoint, which controls a headless Chromium browser and can execute arbitrary code (`p.evaluate(code)`), lacked both authentication (`checkOperator`) and rate limiting (`checkRateLimit`). This exposed the application to unauthenticated SSRF (navigating to internal services), RCE, and DoS (launching unbounded browser instances).
**Learning:** System endpoints intended strictly for internal agent operations or system administrators might be inadvertently exposed without appropriate operator authentication or rate limiting if a "secure by default" middleware is not globally enforced on all mutating endpoints.
**Prevention:** Always ensure that all state-changing or sensitive API endpoints, especially those that bridge to powerful internal tools or APIs, explicitly invoke the standard operator authentication and rate limiting helpers (e.g. `checkOperator` and `checkRateLimit`).
