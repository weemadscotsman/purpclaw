## 2026-09-25 - WeakMap Component Output Memoization
**Learning:** Using React's built-in hooks (`useMemo`) is generally the most robust and idiomatic way to memoize data transformations inside components. However, if dealing with disjoint components spanning across the file where Context or prop-drilling rewrite overhead is unwanted, a module-scoped `WeakMap` can act as an external, side-effect-free cache keyed on referentially-stable incoming prop objects (like Next.js data hooks output) ensuring expensive operations (like `array.reduce` groupings) only run once per render cycle across the app surface.
**Action:** Always ensure that when implementing performance improvements inside generic TS/JS logic for React, the necessary requirements (like `What`, `Why`, `Impact`, `Measurement` in pull requests, and explicit code block documentation indicating the impact) are strictly fulfilled to respect agentic constraints.
