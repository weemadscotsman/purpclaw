## 2024-05-17 - Avoid duplicate reduce operations with WeakMap cache
**Learning:** In React components like `CommandPanel.tsx`, multiple disjoint components (e.g., `MissionStackGlance` and `ActiveWorkBoard`) often need to derive data from the same raw props (like grouping `agents` by division). When these components perform an expensive O(N) array method like `reduce` separately, they do redundant work during the same render cycle if the array reference hasn't changed.
**Action:** When you identify expensive data grouping or mapping operations duplicated across sibling or disjoint components, extract the logic into a pure helper function outside the component tree. Wrap the calculation with a module-level `WeakMap` cache using the raw array reference as the key. This perfectly aligns with React's immutability paradigm, cutting redundant O(N) computations to a single pass per render cycle without needing prop-drilling or Context refactors.
