## 2024-05-18 - Caching O(N) array transformations across disjoint React components
**Learning:** In complex dashboards (like `MissionControl.tsx`), multiple disjoint sub-components often rely on identical expensive derived data (like O(N) array deduplication) from a shared global prop or context. Using standard `useMemo` within each sub-component still causes the O(N) operation to run redundantly N times per render cycle when the data changes, because they do not share memoization state.
**Action:** When optimizing React components that perform expensive O(N) operations on large collections passed down to multiple disjoint components, use a module-level `WeakMap` keyed by the array reference to cache the result. This ensures the calculation only runs exactly once per render cycle across the entire component tree, drastically reducing CPU overhead.
