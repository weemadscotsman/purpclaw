## 2024-05-14 - Redundant Array Processing in React Components
**Learning:** `getUniqueAgents` / `uniqueAgents` (an O(N) operation filtering and mapping a large dataset) was being executed directly in render bodies multiple times per cycle across sibling components due to prop-drilling or hook usage without caching. The standard `useMemo` is insufficient here because each component calls the utility independently with the same large root state object.
**Action:** When a global state object (like `data.agents`) is processed by disjoint components simultaneously, use a module-level `WeakMap` keyed on the state object reference to cache the O(N) result. This securely memoizes the processed result without polluting component state, and automatically garbage collects when the root data reference updates.
