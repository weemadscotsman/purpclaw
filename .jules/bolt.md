## 2026-08-28 - Avoid redundant collection deduplication across useMemos
**Learning:** In React components dealing with large real-time datasets (like `MissionData`), calling deduplication functions (e.g., `uniqueAgents`) inside multiple separate `useMemo` hooks is an anti-pattern. Even though the results are memoized *within* each hook, the actual O(N) deduplication work is still performed multiple times (once for each hook) whenever the source data updates. In `LiveSystemMap`, this caused the O(N) deduplication to run 3 times per data tick instead of 1.
**Action:** When a computed/deduplicated list is needed by multiple downstream `useMemo` blocks, always create a primary `useMemo` specifically for the deduplication step. Then pass this memoized result into the dependency arrays and bodies of downstream `useMemo` blocks. This ensures the expensive operation runs exactly once per data change, saving CPU cycles on frequent updates.
