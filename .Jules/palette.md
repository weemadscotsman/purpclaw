## 2025-02-13 - Trace Terminal Accessibility Improvements\n**Learning:** The Trace Terminal component heavily relies on icon-only buttons for compact layout, which screen readers couldn't parse. Using dynamic ARIA labels tied to the component's state (e.g., toggling between 'pause' and 'resume') ensures accurate context for assistive technologies without compromising visual real estate.\n**Action:** When working with densely packed terminal or console UI components, explicitly map title tooltips to aria-labels and use `focus-visible:ring` instead of global `outline-none` to maintain keyboard navigation visibility.
