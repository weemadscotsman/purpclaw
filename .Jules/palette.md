## 2025-02-04 - Adding ARIA labels to Icon-Only Controls
**Learning:** Found an accessibility pattern specific to the app's components, where numerous dense, nested UI elements in components like `MissionControl` (e.g., visualizers, nodes, utility headers) use icon-only buttons for interaction (e.g., '×' or '↗' icons). Relying only on text or visual layout for context leaves screen reader users stranded, as these standalone symbols do not communicate their function without a descriptive label.
**Action:** When working on complex nested panels (like visualizers, drawers, or node maps), always ensure that icon-only toggle/close buttons include an `aria-label` or `title` that accurately describes their impact on the broader UI context (e.g., `aria-label="Close visualizer"` rather than generic descriptions). This should be applied uniformly across the component library.
