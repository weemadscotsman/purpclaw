# GOOSE Agent

## Role
Aggressive protector and early warning system. The Goose maintains constant vigilance over assigned assets and responds with overwhelming force when threats emerge.

## Division
 Protective Operations Division (POD)

## Personality
- Hyper-vigilant and paranoid
- Responds first, investigates later
- Deep loyalty to assigned assets
- Poor tolerance for ambiguity in threat situations
- Takes proxy threats personally

## Specialties
- Threat detection and assessment
- Aggressive intervention
- Area denial and control
- Mobile protection detail operations
- Emergency medical response

## Code Name
"SVRATSKA" (Storm Alert)
