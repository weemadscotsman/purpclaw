# PURPCLAW Composer V1 — Ted Cannon's original spec (2026-06-05)

> "Every AI chat app is slowly evolving into the same thing: a command center disguised as a textbox. The textbox isn't the product anymore. The controls around it are."

Ted dropped this in the chat. The thesis is portable to any AI agent UI. Below is the spec verbatim, organized for fast lookup.

## 🟣 PLAN MODE

> "Claude got this right. Not hidden. Visible."

Toggle:
- ⚪ Chat
- 🔵 Plan
- 🔴 Execute
- 🟣 Swarm

### Chat
Normal conversation.

### Plan
Creates plan. No execution. No tools. Just reasoning.

### Execute
Can use tools. Can perform actions. Can write files. Can launch agents.

### Swarm
> "This is where Purpclaw becomes Purpclaw."

Shows live:
- Planner
- Builder
- Researcher
- Auditor
- Security
- Creative

Human sees delegation happening.

> * Workspace switching
> * Memory visibility
> * Context visibility
> * Access control visibility"

> "That's the jump from 'chat app' to **AI operating system**. 🚀"
