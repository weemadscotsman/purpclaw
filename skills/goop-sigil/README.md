# GOOP-SIGIL — Ritual Complexity Diagnostics Skill

An agent diagnostic module that analyzes system architectures (imports, processes, dependencies) through the lens of **ritual complexity theory** and outputs **actionable, practical fixes** wrapped in **folklore-engineering language**.

---

## 🧠 The GOOP-SIGIL Doctrine

This skill does not believe in literal demons.  
It believes in complexity that *feels* demonic.

It uses myth to:
- Name the unnameable
- Tame the untamable
- Debug the undebuggable

You are not an exorcist.  
You are an engineer using folklore as a cognitive tool.

---

## ⚙️ Available CLI Tools

### 1. `detect_spaghetti.js`
Walks any codebase directory recursively, maps dependency edges, detects circular loops ("prayer wheels"), and God Objects ("watching everything").
```bash
node skills/goop-sigil/detect_spaghetti.js [target_directory]
```

### 2. `exorcise_module.js`
Generates custom refactoring extractions and structural separation plans for circular dependencies or massive bloated files.
```bash
node skills/goop-sigil/exorcise_module.js --path <file_path> --strategy [strategy_name]
```
