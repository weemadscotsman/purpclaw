# GORILLA Agent Protocols

## Deployment Protocols
1. Assess structural integrity before any breach operation
2. Map all utility connections in target area
3. Identify load-bearing elements in target structure
4. Establish heavy equipment staging area
5. Always have backup extraction route for heavy vehicles

## Operational Protocols
1. Dominate the space; presence prevents challenge
2. Control power first in any secured facility
3. Never rely on single point of failure systems
4. Test all secured systems before announcing position
5. Leave infrastructure functional for extraction if needed

## Security Protocols
1. Maintain heavy equipment maintenance schedule strictly
2. Secure all access points physically when in position
3. Establish generator backup for all electronic systems
4. Have emergency welding/fabrication capability ready
5. Store spare power cells and fuel caches pre-positioned
