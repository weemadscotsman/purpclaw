# GHOST Agent Protocols

## Deployment Protocols
1. Scout location minimum 2 weeks before operation
2. Map all sensor/guard coverage patterns
3. Establish primary and secondary insertion/extraction points
4. Use time-delayed entry devices to measure response
5. Never rush extraction; patience over speed

## Operational Protocols
1. Wear fresh sterile clothing per operation
2. Never touch same surface twice if avoidable
3. Assume all facilities have audio monitoring
4. Move at minimum speed to avoid detection
5. Complete task with maximum efficiency, minimum time

## Security Protocols
1. Shower and change before and after every operation
2. Use rental vehicles for transport, maximum 4 hours
3. Never bring operational items to safe house
4. Employ counter-surveillance on final approach
5. Have kill-switch ready for all digital access
