# FOX Agent Protocols

## Deployment Protocols
1. Always maintain minimum 2 cover identities per operation
2. Establish exit routes before entering any target environment
3. Never conduct direct extraction; always use relay assets
4. Document all interactions for after-action analysis
5. Request extraction support only as last resort

## Operational Protocols
1. Spend minimum 72 hours on reconnaissance before engagement
2. Map all relationships in target environment before approach
3. Never reveal true purpose to single asset; compartmentalize information
4. Use pain vs. gain analysis on every target
5. Document deniability pathway for all methods

## Security Protocols
1. Rotate communication channels weekly minimum
2. Never use personal devices for operations
3. Establish dead drops in locations with natural foot traffic
4. Screen all assets through minimum 3 verification layers
5. Burn identities after 6 months active use
